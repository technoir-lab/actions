# Technoir Lab GitHub Actions

GitHub Actions shared by Technoir Lab projects.

| Action | Description |
| --- | --- |
| [setup-kotlin-multiplatform](setup-kotlin-multiplatform/README.md) | Caches Kotlin/Native toolchains for Kotlin Multiplatform builds. |

## Versioning

All actions in this repository are released together under a single version tag. Reference an action by its directory and an exact release tag, and let Dependabot keep it up to date:

```yaml
- uses: technoir-lab/actions/setup-kotlin-multiplatform@v1.0.0
```
